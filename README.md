# Gabriel Moraes — Portfólio de IA e Desenvolvimento

Portfólio pessoal com projetos de desenvolvimento de software, automação e uso prático de inteligência artificial.

## Projetos

- **Central TEES:** sistema web corporativo com módulos e dashboards — em desenvolvimento.
- **JARVIS GB:** extensão Chrome com recursos de IA para análise de questões — protótipo funcional em evolução.
- **Aplicativo TEES:** aplicativo corporativo Android para processos HSEQ — em desenvolvimento.

## Tecnologias e interesses

JavaScript, Node.js, Firebase, APIs REST, GitHub, LLMs e automação.
